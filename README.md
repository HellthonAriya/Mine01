# کافهٔ دمسا — قالب شمارهٔ ۱ (Café)

وب‌سایتِ پریمیومِ موبایل‌اول و راست‌به‌چپ برای کافهٔ دمسا.
طراحی سینماییِ شبانه با پالتِ قهوه/زعفران/فیروزه و امضای بصریِ گره‌چینی.

## اجرا
هیچ build لازم نیست. کافی‌ست `index.html` را در مرورگر باز کنی،
یا یک سرورِ ساده اجرا کنی:

```bash
python3 -m http.server 8000
# سپس باز کن: http://localhost:8000
```

## ساختار
```
index.html              ساختار صفحه + اسپرایت SVG (آیکن/تصویرسازی)
assets/css/styles.css   هویت بصری، RTL، حالت تاریک/روشن، ریسپانسیو
assets/js/menu-data.js  دادهٔ منو، نظرات، رویدادها، سطوح باشگاه
assets/js/app.js        تعامل‌ها: ناوبری، انیمیشن، منو، رزرو، گالری، …
```

## بخش‌ها
هیرو · دربارهٔ ما (+تایم‌لاین) · منوی ویژه (فیلتر/جست‌وجو) ·
منوی کامل (۱۲ دسته، جزئیاتِ هر آیتم) · **رزرو میز** (کانالِ اصلیِ کنش) ·
نظرات · گالری (لایت‌باکس) · رویدادها (+شمارش معکوس) · باشگاه مشتریان ·
تماس و نقشه و سؤالات · فوتر · ناوبریِ پایینِ موبایل + دکمهٔ شناورِ رزرو.

## نکته‌ها
- **بدون سبد خرید / سفارش آنلاین / ارسال.** تنها مسیرِ کنشِ مشتری «رزرو میز» است؛
  منو فقط برای نمایش و مشاهدهٔ جزئیات کاربرد دارد.
- تصاویر فعلاً **تصویرسازیِ SVG** هستند تا همیشه و یک‌دست رندر شوند؛
  برای نسخهٔ نهایی، عکاسیِ واقعی جایگزین شود.
- فونت‌ها (Vazirmatn / Lalezar) و GSAP از CDN بارگذاری می‌شوند؛
  در نبودِ شبکه، صفحه با فونتِ سیستمی و بدونِ انیمیشنِ اسکرول هم درست کار می‌کند.
- دسترس‌پذیری: فوکوسِ کیبورد، احترام به `prefers-reduced-motion`، ساختارِ معنایی.

> این قالبِ ۱ (Café) است. قالب‌های رستوران و کافه‌رستوران در گام‌های بعدی.
